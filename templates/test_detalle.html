Cómo leer los números

p50 — de cada 100 pedidos, 50 tardaron menos que este valor. La experiencia típica.
p95 — de cada 100 pedidos, 95 tardaron menos que este valor y solo 5 tardaron más. Es el número que define si la app se siente bien.
p99 — de cada 100 pedidos, 99 tardaron menos que este valor. La cola extrema.
rps — pedidos por segundo que el servidor logró procesar en ese escalón.
n — cuántas mediciones entraron en ese escalón. Cuanto más chico, menos confiable es el percentil.
60.000 ms — es el tope del test: cada pedido se corta a los 60 segundos. Ese valor significa "no respondió a tiempo", no un tiempo real de respuesta.

Un p95 bajo es buena noticia. Uno alto es grave, porque no describe un caso raro: describe lo que le pasó a casi todo el mundo.
